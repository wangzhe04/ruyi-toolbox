# 06 · 本地资料库检索 MCP

> 状态：待实施；依赖 [材料格式 v1](05-document-processing-plan.md)。研究依据见 [04 §3](04-research-and-decisions.md)。首版目录 `mcp/knowledge-library/`，包 `ruyi_knowledge_library`。

## 1. 用户结果与边界

用户选择一组资料，问“不同版本的验收要求有哪些变化”，如意取到可核对的片段后回答。组件负责入库、检索和原文，不内置另一个聊天机器人，不接管主仓记忆/会话库，不自动扫描整块硬盘。

首版接收 PDF/图片的材料 v1，以及本地 TXT/Markdown。原生 Office 可后续增加专用导入器；不能因为解析内核声称支持就跳过格式验收。扫描只覆盖登记的目录，默认不跟随 junction/symlink、不进入隐藏系统目录和凭据目录。

## 2. 架构选择

SQLite 保存 sources、documents、chunks、index_generations、jobs 和全文索引；向量存与 generation 绑定的固定维度文件。先做精确扫描，默认 BGE 轻量路线，比较 Qwen 增强档；FTS5 使用明确的中文切分策略，不能直接把默认 unicode tokenizer 当中文方案。

语义模型缺失时可以显式降级关键词模式，返回 `mode=lexical`；不得声称语义检索仍正常。每代索引记录解析器版本、分块参数、tokenizer、embedding 模型 revision/维度、归一化和分数配置，更换其中任一项须重建相关数据。

先由如意调用文档解析并把授权的材料清单交给知识库；不隐式访问另一个组件进程或私有目录。自动解析整目录作为 K2 功能，需额外明确组件调用发现接口后才能实施。

## 3. 分块与检索

1. 按标题和段落切块，按所选模型 tokenizer 计算长度，预留指令 token；禁止按字符数假设不会截断。
2. 表格按表头加连续行切块，重复表头但保留原始单元格引用；不在数字中间切断。
3. 基线比较 256/384 token 上限及 32/64 overlap，最终值由开发集固定，盲测不调参。
4. 关键词、向量各取候选，先按有效 generation 和目录授权过滤，再 RRF；可选 reranker 只看有限候选。
5. 去重相邻重复块，保留文件版本差异；返回 TopK 原文与引用，而非在组件内部编造答案。
6. 相似度不是“答案正确率”。无结果/低相关性阈值由标注集校准，返回状态和证据，最终回答仍需如意核对。

## 4. 工具与事务

| 工具（拟议） | 行为 |
| --- | --- |
| `library_index` | 输入授权 sourceId、材料清单/文本路径，返回 jobId；默认增量 |
| `library_search` | query、sourceIds、topK（默认 8，上限 20）、cursor；返回块和出处 |
| `library_read` | documentId、blockIds、maxChars，取相邻原文并验证来源版本 |
| `library_status` | 索引模式、代次、进度、未入库/失败文件 |
| `library_remove` | 删除指定 sourceId 的派生索引，不删除源文件 |
| `library_cancel` | 取消索引作业，已发布 generation 保持可查询 |

新增/修改先写暂存 generation，向量和 SQLite 均完成后原子切换可见代次；取消和断电不能留下“全文已新、向量仍旧”的混合状态。mtime/size 只用于快速筛选，内容哈希才判断版本；同名替换测试必须改变哈希。

删除采用墓碑，在确认源目录扫描成功后才处理缺失文件。网络盘掉线或权限失败不能当全库删除。人工撤销目录授权应立即阻断查询，其后清理索引和缓存。搜索和取原文均检查来源是否有效；无法确认时标 stale/source_unavailable，不给“已验证原文”状态。

## 6. 拟定验收与升级触发

盲测 Recall@5 ≥85%（命中人工相关块口径），nDCG@10 不低于最强单路基线；同义问法子集相对词法 Recall@5 提升 ≥10 个百分点，否则不默认启用重模型。引用地址/页/块一致率 100%，无答案题错误给出“充分证据”的比例 ≤5%。样本较小须同时报分子分母，不能宣传为普遍准确率。

标准 CPU 机、5 万块、topK=8、含查询 embedding、不含冷加载的热查询 p95 目标 ≤2 秒；实测不达标再引入 ANN/Qdrant local，不悄悄缩小统计范围。冷启动单列。重排序仅在 nDCG@10 增益 ≥0.03 且延迟仍过门槛时成为默认。

已确认删除/撤权后查询返回该源的条数必须为零。升级先建新代次，成功后切换；回退直接恢复旧代次和匹配模型。证据链接不可在模型升级后静默改变所指原文。
