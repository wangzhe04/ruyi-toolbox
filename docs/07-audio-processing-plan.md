# 07 · 长音频与会议材料 MCP

> 状态：待实施。复用现有 asr-shim/asr-stream，不改变麦克风默认体验。目录建议 `mcp/audio-processing/`，包 `ruyi_audio_processing`；调研见 [04 §4](04-research-and-decisions.md)。

## 1. 分两次交付

A1：已有录音文件 → 可恢复转写 → 带片段时间范围的记录/字幕 → 如意现有会议纪要流程。首版 WAV/MP3/M4A/FLAC，目标最长 2 小时；视频先不承诺。

A2：强制对齐和可选说话人区分。系统声音采集、会议平台接入、真人身份识别、实时同声传译不在首版。会议总结交给如意，不在工具里另调用云端 LLM。

当前 ASR 上传上限 25 MiB，整段 verbose_json 的 segments 为空；不能用总时长按字数均分后冒充真实时间戳。A1 允许语音切段得到粗时间范围，必须标 `timing=segment`；A2 验证对齐后才标 `timing=aligned`。

## 2. 管线与接口

管线：输入校验/哈希 → 解码重采样 → 语音活动分段 → 顺序转写 → 去重拼接 → 可选对齐/说话人 → 导出。

优先评估独立、版本固定的本地解码后端；如引入 FFmpeg，记录实际构建与再分发条件，禁止任意命令拼接。音频路径通过参数数组传递。长文件需要可恢复缓存时写组件内部 job 目录，安装说明明确临时音频保留策略；不继承现有 shim“音频永不落盘”的表述。

| 工具（拟议） | 行为 |
| --- | --- |
| `audio_submit` | 路径、语言、热词、profile、幂等键；返回 jobId |
| `audio_status` | 总时长、已处理区间、阶段、错误及输出位置 |
| `audio_read` | jobId、时间范围、cursor，按段读取转写 |
| `audio_export` | TXT/JSON/SRT/VTT、新输出目录，带来源哈希 |
| `audio_cancel` | 取消并保存已完成区间 |

每段含 startMs/endMs、text、speaker（可空）、timing、ASR 模型版本、sourceSha256、warning。时间相对原始音频，重采样后仍保留原始偏移；边界重叠去重须保留处理日志元数据，不能凭大模型改写原话。

## 3. ASR 复用方式需要先解决

如意可能动态分配 toolbox 服务端口，组件不能硬编码 8790，也不读取主仓私有 config 猜端点。A0 对比：

- 独立运行：安装/启动参数显式指定本地 ASR baseUrl，并验证 `/health` 的组件身份；端口改变由配置更新处理。
- 如意自动运行：主仓增加受控的本地能力发现/调用桥，只返回已启用端点和能力，不给密钥；需修订两仓公开契约。
- 独立加载同一模型：部署自包含，但重复运行时/显存；仅作为无法共享服务时的独立档。

决定：A1 支持显式本地端点；要宣传“自动复用如意当前语音配置”必须完成第二条主仓工作。默认不接云端转写；如未来增加必须显式标记网络和数据去向。

## 4. 实施步骤

| 步骤 | 工作 | 交付/退出条件 |
| --- | --- | --- |
| A0 | 解码、切段、ASR 路线评测；和 faster-whisper 比较 | 选择切段长度/重叠/静音规则；登记准确率和资源，不以短合成语音替代真人样本 |
| A1a | 有界内存解码、缓存、逐段记录和恢复 | 2 小时文件完成；缓存键包含源哈希/模型/语言/热词/切段配置 |
| A1b | 本地 ASR 调用、重试和超时 | 每段小于上传上限；端点身份错误时停止；失败段可重试且不重复最终文本 |
| A1c | 时间轴、分页、导出 | 粗/精时间来源明确，SRT/VTT 可读，原音频不修改 |
| A1d | 接如意纪要模板 | 结论带时间出处；没有负责人/截止日就标待确认 |
| A2a | Qwen ForcedAligner 与 WhisperX 对齐比较 | 中文及中英混排对齐误差、显存与安装结果；选择一个增强档 |
| A2b | pyannote 等说话人候选核验 | 模型获取条件/离线方式明确；无模型时只降级此功能 |
| A2c | 多说话人、重叠语音、长静音评测 | 不确定标签为 unknown，不能强制把所有人声归给已有角色 |

## 5. 评测与验收

样本至少 12 段、合计 120 分钟：中文独白、两人对话、三至五人会议、中英数字术语、噪声/远场、静音/重叠各两段；另有一份 2 小时耐久样本。每类一段开发、一段盲测。采用公开许可或授权录音，不将私人会议提交 Git。

A1 按中文 CER、英文 WER、专名/数字精确率分项报告。相较同后端对人工切好的短段，长文件 CER/WER 恶化不超过 2 个百分点；静音样本不能出现持续虚构文字；失败和跳过区间 100% 可见。原文件哈希不变，重启后只补未完成段。

A2 人工标注至少 200 个边界，报告 p50/p95 绝对误差，拟定 p95 ≤500ms；说话人报告 DER，并注明 collar=250ms、是否计重叠语音。非重叠测试集 DER 目标 ≤15%；未达标就作为实验选项，不能默认输出看似确定的身份。

速度使用 RTF=处理秒数/音频秒数，CPU/GPU 分别测冷/热与峰值资源，不借用上游倍速。取消目标 5 秒内停止工作进程；ASR 服务共享时仅取消本作业，不杀掉麦克风正在使用的服务。已取消的延迟回包必须丢弃。

## 6. 保存与回退

默认成功后清理中间 PCM，保留转写和元数据；失败作业保留恢复所需缓存，提供明确清理动作和期限。源文件、模型或参数改变产生新作业身份。对齐/说话人失败可交付基础转写但整体状态注明 partial；用户能够关闭增强档恢复 A1。
